# Проект

Тема WordPress для сайта разработчика сайтов для психологов (greendiz, psy.greendiz.ru). Классическая тема, корень репозитория — корень темы. Деплой по FTP в `wp-content/themes/greendiz-psy/` (без `acf/`, `plugins/`, `.git`, `CLAUDE.md`, `CONCEPTS.md`, `README.md`).

# Правила работы

- Mobile-first в дизайне и коде.
- Комментарии в коде не писать.
- В ответах кратко: только важное (вопросы, что нужно сделать пользователю, что нужно знать). Не пересказывать сделанное. Не уверен — спросить до правок.
- Пользователь новичок в GitHub: объяснять действия с git простыми шагами.
- Анимации не отключать по prefers-reduced-motion.

# Структура

- `css/`, `js/`, `img/`, `fonts/` — в корне темы, без `assets/`.
- `inc/` — подключаемые модули (`helpers`, `setup`, `enqueue`, `rewrite`, `schema`, `blog`, `seed`).
- `template-parts/` — части шаблонов; главная разбита на `template-parts/home/*`.
- Префикс функций и констант темы: `gdpsy_` / `GDPSY_` (без пересечений с плагином Greendiz Blog).
- Плагин `plugins/greendiz-blog/` — импорт статей блога, хранится здесь для правок.

# Концепты

Файлы концептов лежат в `wp-content/concepts/<slug>.html`, правки — вместе с Claude. Правила для файлов — в `CONCEPTS.md`, соблюдать при любых правках концептов.

# Плагины и настройки

ACF Pro, Classic Editor (Gutenberg отключён), Rank Math SEO, Greendiz Blog.

- Источник правды по полям ACF — `acf/acf-export.json`. После любых правок полей отдавать обновлённый файл для импорта.
- Тексты главной — из ACF страницы (`front_page`), контакты и цены — со страницы опций `acf-options`.
- Цены нигде не хранить в коде: пустая цена не выводится, для расчётов — 0.
- SEO: все данные выводить сразу в HTML на сервере, JS — только для интерактива.

# ЧПУ

- Записи: `/blog/%postname%/`, рубрики и метки под `/blog/`.
- Портфолио (`portfolio`): `/portfolio/название/`, `with_front` = 0.
- Страница «Блог» (slug `blog`) — страница записей.
- Фильтр портфолио: параметр `case-type` (`project` / `consept`), работает без перезагрузки.
