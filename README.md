# Greendiz Psy

Классическая тема WordPress. Корень репозитория — корень темы. Подробности и правила — в `CLAUDE.md`.

- `acf/acf-export.json` — поля, тип записи и страница опций для импорта в ACF (Инструменты → Импорт).
- `plugins/greendiz-blog/` — плагин импорта статей.
- На хостинг: все файлы, кроме `acf/`, `plugins/`, `.git`, `CLAUDE.md`, `CONCEPTS.md`, `README.md`, в `wp-content/themes/greendiz-psy/`.
